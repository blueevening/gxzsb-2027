# 大纲分值更正 + 答题页按钮与信息层级

## Report

## [S1] Problem
首页专业合卷写成「10题40分」误导；答题页重复「下一题」、答完仍堆交卷/退出、错因标签突兀、无保存反馈，页面乱、重点不清。

## [S2] Design
### 首页/考纲分值（必须与大纲一致）
- 数学 150：单选 10×5=50 · 填空 4×5=20 · 解答 7×8=56 · 应用 2×12=24
- 英语 150：词汇语法单选 20×2=40 · 阅读单选 50 · 填空 5×2=10（阅读+填空 60）· 英译汉选择 8×3=24 + 汉译英 1×8=8（翻译 32）· 应用文写作 1×18=18
- 专业合卷 300：单选 30×4=120 · 判断 15×3=45 · 填空 30×2=60 · 应用 6×12.5=75
文案固定展示，不再用会算错的 mix 拼接。

### 答题页
- 操作区：未提交 →「提交答案」主按钮 + 上一题/收藏；最后一题才见「交卷」（仅模拟考）
- 已提交/看解析 →「下一题」唯一主按钮；不显示「交卷」「退出考试」
- 退出考试仅在未交卷的模拟考顶栏或菜单一处
- 错因 chips 改为浅底圆角小标签，不抢主反馈
- 切题/提交后 toast「已保存」轻反馈（节流）

## [S3] Out of Scope
不改题库题目内容；不改分值计算规则。
