# gxzsb-2027 · 广西专升本刷题站

纯静态、可 GitHub Pages 部署的广西专升本（电子信息类）备考练习工具。中文界面，亮/暗主题。

在线地址：https://blueevening.github.io/gxzsb-2027/

## 科目

| 科目 | 模块 | 分值 |
|------|------|------|
| 高等数学 | 公共基础 | 150 |
| 英语 | 公共基础 | 150 |
| 电工电子技术基础 | 专业综合 | 100 |
| C语言程序设计 | 专业综合 | 100 |
| 计算机网络基础 | 专业综合 | 100 |

专业综合三门合卷（300 分 / 150 分钟）。

## 功能

- **顺序练习**：按题库录入顺序稳定出题，刷新/重开不乱序
- **每日 30 题**：按日期锁定固定题组，只统计该组完成进度（上限 30）
- **章节 / 考点 / 错题 / 收藏** 多种练习；错题按遗忘曲线到期重做
- **模拟考试**：选科目或合卷、限时、交卷出分、对答案、历史记录
- **数据分析看板**：近 7 日学习量、正确率趋势、科目进度、薄弱知识点 TOP
- **单词本**、**公式速查**、**学习一刻**、**考纲**、**真题库**
- **登录 / 注册 + 云同步**（Supabase）：失败重试、离线排队；无密钥时纯本地可用
- **重置学习数据**（只清学习记录）≠ 退出登录 ≠ 清除本机全部数据

## 本地打开

双击 `index.html` 即可（`file://` 可用，不依赖构建）。

或起本地服务：

```bash
npx serve .
# 或
python -m http.server 8080
```

Service Worker 仅在 `http(s)` 下注册，`file://` 会自动跳过。

## 账号 / 数据说明

- 学习数据默认保存在浏览器 `localStorage`（key 前缀 `gxzsb.*`）
- 启用 Supabase（`sb-config.js`）时需登录/注册，进度云端同步；主题偏好仅存本机
- **注册新账号**会备份并清空本机旧学习数据，避免串号
- **退出登录**保留本机学习记录；**重置学习数据**只清做题记录；**清除本机全部数据**才抹掉一切
- 可在「我的」导出 / 导入 JSON 备份

